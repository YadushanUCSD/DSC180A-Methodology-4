**What is the most interesting topic covered in your domain this quarter?**

The most interesting topic covered in my domain this quarter is using image recognition with a webcam to map movements. This is done to map movements to sound generation.

**Describe a potential investigation you would like to pursue for your Quarter 2 Project.**

I would like to investigate how gesture can be intuitively linked to full speech. Technology currently exists but it is a very slow process that does not allow the speaker to express themselves meaningfully. By incorporating the webcam and gesture controls, the user may be able to express themselves better and more efficiently.

**What is a potential change you'd make to the approach taken in your current Quarter 1 Project?**

If I had to change something about my approach this quarter, I would like to do more group work in order to cover more ground faster. As of right now, we are all learning by doing individual projects, and while there is merit in that, I do think that working together will help us get farther, especially given our time constraint.

**What other techniques would you be interested in using in your project?**

I would be interested in using a model to remember gestures and essentially be able to create a personalized language for the user. This would involve more use with the webcam but also work with storing all the relevant data, which is currently something I have not worked with yet on this project.
